PROJECT RULE:

Never implement future tasks unless explicitly instructed.

Before writing code:
1. Explain the design.
2. State the mathematical/engineering assumptions.
3. State which files will change.
4. Implement only the current task.
5. Provide commands to test it.
6. Stop after the current task.

Never hide important functionality behind a high-level abstraction when the goal is to understand the underlying mechanism.

Prefer simple, readable implementations over clever implementations.
